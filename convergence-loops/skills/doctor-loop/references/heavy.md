# doctor-loop の重厚の段だけで走らせるもの

## 重厚のみ: 独立再導出と模範照合

- **rederiver（`blind-judge`・実装を遮断）**: この役はツールを持たないので実装ファイル・コミット履歴に触れられない。プロンプトには「**渡されていない現行構成を推測で再構成することを禁じる。** 渡された目的と制約（P0-3 の要約の前半のみ——現行のモジュール構成は渡されない）だけから、あるべきモジュール構成と仕組みを独立導出しろ」と書け。rederiver が返すのは独立導出（と `unverifiable` の申告）だけである。**突合と verdict の確定は比較係（`blind-judge`・新しいコンテキスト・木や候補・scout の所見は渡すな）に委ねろ**——rederiver の独立導出と、prospector が書いた現行構成の記述（P0-3 の後半）の 2 つだけを渡し、構造差の有無でゲートの 3 語彙を確定させる（routing は P4「ゼロベース乖離」「独立検証不能」）。**prospector が構造差の有無を自分で確定するな。** 構造差が候補の種。表現の違いは差ではない。
- **模範照合（比較 scout＝`investigator`・P1 の所見を渡すな）**: 対象と同種の成熟した一線級リポジトリ・製品を 2〜3 特定し、対象範囲に対応する箇所の作りを読み、差を**メカニズム＋適用条件**で報告させろ。**「◯◯社・有名 OSS がやっているから」は根拠として禁止**——彼らの解は彼らの制約の関数であり、その制約がこちらで成立するかを必ず添えろ。参照した模範と読んだ箇所は報告に書け。
