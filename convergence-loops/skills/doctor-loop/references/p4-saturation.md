# doctor-loop の P4（ラウンドと飽和）

## P4: ラウンドと飽和（木版）

**1 ラウンド＝P1→P3 を 1 周。** 2 ラウンド目以降の規律:

- scout は毎ラウンド**新しいコンテキスト**で起動しろ。前ラウンドの候補・経緯を渡すな。prospector 側で安定キーにより新規だけを拾え。
- P2 は**新規のノードだけ**に、毎回新しいコンテキストで回せ（P3-3 由来の親のノードと、抜き取り検査を含む）。
- 計器（P1 第 1 層）は決定的なので再実行不要。
- **上方向の展開もラウンドの仕事**——葉が増えなくても、既存のノードに新しい親が生えたらそのラウンドは新規ありと数えろ（数え方は下の「新しいノード」の定義に従う）。

**収束（理論的飽和）で止めるのが正常終了**。飽和の三条件は「**生えない・揺らがない・欠けていない**」: **連続 2 ラウンドで新しいノードが生えなくなった時点で（葉も親も）、飽和の抜き取り検査（判定が揺らがないか）と cartographer の突合（被覆が欠けていないか）を同時に走らせろ。** どちらも通れば（重厚では rederiver の `pass` も揃えば）飽和である。**「新しいノード」と数えるのは、確定判定が推奨・条件付き・検証不能となったノードだけ**——事実誤り・既決着・棄却の新規は安定キーに記録するがカウンタを動かさない。飽和は雑音の新規性ではなく**価値の新規性**で測る（広い面積では雑音の新規が尽きないため、生の新規性では飽和に届かない）。**連続カウントは、抜き取りで判定が覆ったとき・収束ゲートが `redesign-needed` を返したとき・thrash で面積を割り直したときに、いずれも 0 へ戻す。** 暴走ガードの総ラウンド数は割り直しをまたいで継続計上する。

- **飽和の抜き取り検査**: 新規のノードが空集合のラウンドの自明成立を飽和と認めないための検算である。**刈り込みが止める「以後の検証」の唯一の例外**——検算であって回し直しではない。母集団は確定済みの全判定（推奨・条件付き・棄却・検証不能・事実誤り・既決着）。無作為に 1〜2 割（目安）を抜き、**事実で刈った判定は新しい checker（`inspector`）に、価値判断の判定は新しい refuter（`judge`）に**引き直させろ。**引き直しには元の判定・理由・ラウンドを渡すな**——渡すのはノードの本文と根拠、その根拠が指すファイルの内容だけ（前の判定を見せると検算が追認になる）。覆ったか否かは prospector が安定キーで突合しろ。1 件でも覆ったら飽和ではない——通常ラウンドに戻れ。**結果は（重さ×確度）の層別で報告しろ**——覆り率がゼロのまま続く層は検証過剰、2 割を超える層は検証不足の証拠で、どちらも型への還流で漏斗の段を動かす材料になる。塩梅は感覚でなく、この計器で調整する。
- **cartographer（`blind-judge`・scout の所見を遮断）**: 起動は序盤に先行してよいが、突合は上記の収束確認の時点で行え（盲点を足して回した追加ラウンドが再び連続 2 ラウンド新規ゼロになれば、もう一度）。P0 の面積×レンズとドメイン要約だけを渡し、「この範囲を完全に走査するために要る観点・見るべき場所」の**列挙だけ**を返させろ。突合と verdict の確定は**比較係（`blind-judge`・新しいコンテキスト・木や候補は渡すな）**に委ねろ——cartographer の列挙と、prospector が作った実走査範囲の記録（面積×レンズ×層）の 2 つだけを渡し、`pass`（差分なし）／`redesign-needed`（盲点が候補の有無を変えうる——観点に足して新ラウンドへ）／`unverifiable`（列挙と記録が対応づけられない——飽和を宣言せず依頼者に諮れ）を確定させろ。**prospector が自分の被覆を自分で採点するな**——「掘り尽くした」は本ループで最も重い宣言である。報告には列挙の生出力・実走査範囲の記録・比較係の生の verdict と理由を並べて載せろ。**thrash で面積を割り直したら cartographer は再起動しろ**（入力の面積×レンズが変わっている）。**これ無しで「掘り尽くした」を名乗るな。**
- **ゼロベース乖離（重厚のみ）**: rederiver の `redesign-needed`（構造差）はノードとして木に足して検証しろ。再ラウンド 1 回で解消しなければ、機械では決められない設計の岐路である——依頼者に諮れ。
- **独立検証不能（重厚のみ）**: rederiver が `unverifiable`（正典から目的・制約を独立に取れない）→ pass でも redesign でもないので、飽和を宣言せず依頼者に諮れ。
- **先行議論を洗えていない**: P0-4 が「確認できなかった」で終わったままなら、飽和を宣言せず依頼者に諮れ——決着済みの蒸し返しの可能性が残っている。
- **stuck**: 同じノードが「判定不一致」のまま 2 ラウンド残る → 機械では決められない。昇格ではなく依頼者に諮れ（無人では保留ブランチのまま続行し、要人間判断へ）。
- **thrash**: 新しいノードが出続けて収束に向かわない → **面積の割り方が粗いか、レンズの立て方が誤っている証拠**。処理順は固定: ①P0-2 に戻って面積を割り直す（cartographer は再起動）→ ②割り直し後も続くなら重厚へ昇格 → ③それでも収束しなければ依頼者に諮れ（無人では要人間判断へ列挙して続行）。黙って回数を消化するな。
- **暴走ガード**: 総ラウンドが 6 に達した時点（6 ラウンド目の完了時）で、飽和していなくても停止し、「飽和せず」と残った観点・木の現状を報告しろ。
- **機械に「リポジトリは健全」を宣言させるな。** 飽和が宣言できるのは「この面積×レンズ×この目では、これ以上生えなかった」まで。
