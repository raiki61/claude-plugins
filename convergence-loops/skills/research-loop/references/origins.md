# research-loop の型の正体・正直な限界・由来

## この型の正体（先に一度だけ）

このループは新発明ではない。**系統的レビュー（外部証拠の格付け突合）＋ファクトチェック（一次情報照合）＋敵対検証（反証を試みる独立の目）**の合成で、各部品は EBM/GRADE・報道の校閲・情報分析（ACH・悪魔の代弁人）・質的研究（理論的飽和）・科学哲学（Wimsatt robustness）で数十年運用されてきた。全体の二段構え ──「①外部の定石で自分の座標系を校正 → ②自ドメインの制約で最適化」── も外部視点→内部視点（reference class forecasting）・EBM の定義・守破離と同じ型である。ループ全体の骨格も枯れている ── 情報機関の**情報サイクル**（要求定義→収集→分析→配布→還流）と Peirce の**探究の循環**（仮説生成→検証）に同型で、主張1件の単位構造（claim・evidence・conditions・correction）は **Toulmin の論証モデル**（主張・根拠・限定・反駁）に一致する。新しいのはコスト構造だけ（LLM 並列で①が数時間になった）。由来の対応表は末尾。

## この型が保証しないもの（正直な限界）

- **特定のひらめきを期日までに保証できない**: 生成（P0-7）は確率的な探索で、手筋は当たり率を上げ、P1 が外れを濾すが、「この発見が今日出る」を予定に載せることはできない。型が変えるのは確率分布であって確実性ではない。
- **ドメインの暗黙知**: 現場でしか知られていない制約は、P0 の棚卸しに人間が入れない限りループのどこにも現れない。

## 付録: 由来の対応表（この型は枯れている）

| このループの部品 | 確立した先行手法 |
|---|---|
| 主張の棚卸し→一次情報突合 | 報道のファクトチェック部門（1920年代〜）／系統的レビュー（Cochrane/PRISMA） |
| 出典の格付け | EBM のエビデンス階層（GRADE）／情報分析のアドミラルティ・コード（信頼性×確度） |
| 相違のみ敵対検証・反証を試みる | 悪魔の代弁人（列聖審査 1587〜）／レッドチーム／ACH（競合仮説分析、Heuer/CIA） |
| 判定語彙の固定 | words of estimative probability（Sherman Kent） |
| 独立性の点検・系譜を数えない | Wimsatt の robustness analysis（*illusory robustness*） |
| 訂正の append-only 記録 | 学術出版の正誤表／会計の決算整理仕訳 |
| 新規ゼロが続いたら収束 | 質的研究の理論的飽和（Glaser & Strauss） |
| 外部で校正→ドメインで最適化 | 外部視点→内部視点（reference class forecasting）／EBM の定義／パターンランゲージの適用条件確認／守破離 |
| 2層マップ・白地図 | Wardley マッピング（構成要素の位置と依存の地図→打ち手）に相当 |
| 断面の生成（P0-7 の手筋） | abduction（Peirce＝仮説生成は論理操作）／Polya『いかにして問題をとくか』／TRIZ（特許4万件から発明を約40原理に還元した実証）／構造写像（Gentner）／逆転（Jacobi/Munger）／変則事例（Kuhn） |
| 手筋の木化・総当たり（P0-7 末尾） | 形態分析（Zwicky）／HAZOP（ずらし語×全要素）／FTA・イシューツリー（MECE）／ゲーム木探索の刈り込みと予算配分 |
| 用語の二義展開 | 要件工学の曖昧性レビュー（多義語の読みをブランチにして全て検証） |
| ループ全体の骨格 | 情報サイクル（要求→収集→分析→配布→還流）／Peirce の探究循環／事前登録（protocol registration） |
| 主張1件の構造 | Toulmin の論証モデル（主張・根拠・限定・反駁） |
| 負荷確証の反証探索・生存者バイアス点検 | 反証主義（Popper）／出版バイアス対策（Cochrane）／生存者バイアス（Wald の爆撃機） |
| 雪だるま式追跡 | citation snowballing（系統的レビューの標準手技） |
| 文脈込みの引用・射程の確認 | 全文精査（PRISMA の full-text assessment）／外的妥当性・PICO（EBM）／判例の射程（法学）。文脈剥ぎ取り引用＝quote mining は名前の付いた誤謬 |
| 鍵となる前提の点検 | Key Assumptions Check（情報分析の構造化分析手法） |
| トリップワイヤ・情報の価値順 | 『決定力』（Heath 兄弟）のトリップワイヤ／決定分析の VoI（情報の価値） |
| 型への還流 | AAR（米陸軍の事後検証）／かいぜん・ふりかえり |
| 厚みの統治（降格は依頼者のみ・昇格は自由） | graded approach（原子力 ── 安全重要度に応じた等級の**事前定義**）／職務分離（作業者に自分の検査水準を決めさせない）／フェイルセーフ既定 |
| 確認ラウンドの抜き取り検査 | 受入抜き取り検査（AQL・MIL-STD-105 系）／test-retest 信頼性 |
