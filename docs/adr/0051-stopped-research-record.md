# 0051. 止めた research の記録は空の欄を理由つきで受け、走っている run への finalize は記録を書き換えずに失敗で返す

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 検証器の緩めは人（09:00、受け入れる）。finalize の扱いは回す側の答え（03:40、関所）
- 実装: 0.21.0 に入った

## 文脈

- 走っている run を途中で止める口（`loop.py stop`）を足した。止めた research の run の報告を出すには、検証器が止まった記録の空の欄を拒まない必要があった。安全装置を緩める変更だが、その周は人の関所が発火せず、誰にも聞いていなかった。
- 走っている research の run に finalize を打つと「止まった記録」として検証器を通る挙動があった。

## 決定

- 検証器は、止まった記録に限り、空の欄（問い・制約・主張など）を理由つきで受ける。
- 走っている run への finalize は、記録を 1 字も書き換えずに理由を出して exit 1 で返す。

## 比べた案

作業メモに記載なし。

## 理由

- 止めた run の報告を出すため。
- finalize の扱い: 人が出した依頼がまさに直せと言っている欠陥で、中身が消えないため。

## 結果

- 緩めは止まった記録だけに限る。2 周目の run には、この緩めを広げない・要るなら人に上げるよう縛った。
