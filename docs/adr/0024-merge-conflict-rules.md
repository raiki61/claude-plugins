# 0024. 合流で困ったときの決まり

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人
- 実装: 運用の決まり（仕組みの変更を伴わない）

## 文脈

- 1 周目で止めた複数の run の枝を 1 本に重ねるとき、重ねる担当がどこまで自分で解いてよいかが決まっていなかった。

## 決定

- 重ねる担当が自分で解いてよいのは、文の衝突・件数の定数・両側の意図がそのまま両立する重ね方だけ。
- 重ねるためにコードの振る舞いを変えたら、変えた箇所と理由を報告し、次の run（判定から入る run か合流の run）の依頼として判定に流す。
- 両側の意図がぶつかって、どちらかを捨てないと成り立たないときは、重ねずに止めて人に見せる。能力を減らす重ね方はしない。

## 出どころ
