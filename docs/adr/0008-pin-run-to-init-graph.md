# 0008. 走っている run は init の版の graph に固定する

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人（15:40、独立設計の目 R2 の案を採った）
- 実装: 0.20.1 に入った

## 文脈

- 0.20.0 で、大きな材料の run が P1 の衛生の節で進めなかった。原因は材料の大きさでなく、途中で版を上げた run の盤面が init の版（0.15.0）の graph を掴んだままで、その graph が役を `--output-format text` で起こし、新しい engine が包みとして読めずに捨てていたこと。
- 判定役の直し（盤面を新しい版の graph へ付け替える）と、R2 の案（graph は init の版に固定し、engine が起こした語の出力の形を見て解く）が逆向きだった。

## 決定

- graph は init の版に固定する。明示の指定は要らない（盤面が init の graph を持つことで成り立っている）。
- engine は役の出力の形を見て読み分ける（包みは type=result の object だけ、それ以外は全文を本文として読む）。
- この決まりは run をまたいで効く人の方針でもある。人の方針としての正本は人が書く方針の文書（[review-graph の手順書の「人の方針」](../../graphloops/commands/review-graph.md#人の方針)）で、この ADR は決まったときの文脈と理由の記録である。食い違えば方針の文書が勝つ。

## 比べた案

- 版を上げたとき、走っている run の盤面を新しい版の graph へ付け替える（判定役の案。捨てた）。

## 理由

作業メモに理由の記載なし（人が R2 の案を採った事実だけが残る）。

## 結果

- 走っている run は、版を上げても init の時の graph・指示書・rules・検証器で回る。新しい版の動きが要るなら新しい run を始める。
- 盤面を別の版の graph へ付け替える手順は用意していない。
- 残り: 古い版の graph の起こし方で launch から盤面が進むまで通す検査が無い。
