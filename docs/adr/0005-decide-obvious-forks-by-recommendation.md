# 0005. 自明な分かれ目は回す側が推しで決め、人に上げるのは能力を手放す取捨だけにする

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 人（09:00「残りは全部推しで」「自明なものは聞かないで」）
- 実装: 運用の決まり（仕組みの変更を伴わない）

## 文脈

- 夜の間に、人に決めてほしい問いが 12 件たまった（今あるタイムアウトの扱い・仕様の流れの選び方・CI の見送りの許し ほか）。人の答えを待って run が止まる。

## 決定

- 回す側は、自明な分かれ目を推しで決めて報告する。答えたのが回す側であることを記録に残し、人が後から覆せる形にする。
- 人に上げるのは、能力を手放す取捨（と人の意図が要る物）だけ。人が不在の間は、能力を手放す取捨しか無い物だけ止めて朝の報告に書く。
- この置き場では、回す側が推しで決めた ADR の「決めた人」に、そうと書く。
- この決まりは run をまたいで効く人の方針でもある。人の方針としての正本は人が書く方針の文書（[review-graph の手順書の「人の方針」](../../graphloops/commands/review-graph.md#人の方針)）で、この ADR は決まったときの文脈と理由の記録である。食い違えば方針の文書が勝つ。

- 推しが外れていれば人が覆す。覆すときは新しい ADR で置き換える。
