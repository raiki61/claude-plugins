# 0042. CI の見送りの許しは OS ごとの「欠けてよい能力」の一覧にし、既定は空

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 人（09:00、推しのとおり）
- 実装: 作業枝で済み（0.21.0 には未収録）

## 文脈

- CI を緑に戻す run で、走らなかった検査を合格と分けて一覧で出し、見送りを失敗にする切り替え（FAIL_ON_SKIP=1）で CI を止められるようにした。ただし全部か無しかの切り替えしか無く、workflow は触っていないので CI は見送りでは止まらなかった（見える化だけ）。

## 決定

- CI の各 OS に「欠けてよい能力」の一覧を渡す形にする。既定は空。
- macOS と Windows の CI にも shellcheck を入れる。

## 比べた案

- 全部か無しかの切り替え（それまでの形）。
- 見送りごとに欠けている能力の名前を付け、CI が許す能力の一覧を渡す（見直し役の案。採用）。

## 理由

作業メモに理由の記載なし。

## 結果

- 作業枝の実機の CI で、Windows の見送りは全部許しの一覧で許された。Windows の shellcheck が CRLF で全行に指摘した件は `.gitattributes` で .sh を LF にして直した。
- Windows の許しの一覧は、posix の囲いの検査と同じ件数に揃える（0.21.1 の取りまとめで判定に流す）。
- 残り: 許しの一覧に古い名前が残っても気づく口（R2 の案）。
- 作業枝（0.21.0 には未収録）。
