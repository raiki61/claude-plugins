## 決定

- 回す側の LLM を無くす。`loop.py run` を 1 本のプロセスとして足し、next → 節の種類ごとに実行 → 受け付け → next を回し、人に聞く所か終わりで止まる。`next`・`done`・`launch` は残す。移せない節は会話に返す節として止まって渡す。
- H1 の 5 点: ① 会話は前景の `loop.py run` で見守る（上限 540 秒で「まだ回っている」と戻り、打ち直す。回し手のプロセスは run 自身が切り離して立てる）② engine が起こせない節が出たらすぐ会話に返し、起こせる節は並行で進める ③ 周の数の止め方は `init --stop-after-round` だけ ④ 終了コード 0・10〜14 は run にだけ足し、今の 0/1/2 は変えない ⑤ H1 の土台は 0.21.0。
- その先は H2（判断の任せ先を役に）→ H3（writer を役に）→ H4（プラグインの役と skill）→ H5（既定を画面なしに）。
