# 0045. research-graph は research-loop の上位互換にする（開いた問いは依頼者に渡す）

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人（16:00）
- 実装: 0.20.1 に入った

## 文脈

- research-graph は散文の research-loop（convergence-loops の手順書）の移植。検索語の規律の run が、research-loop の「開いた問いは deep-research に委ねる」導線を「依頼者に渡す」に差し替えていた（6 ファイル、元の手順書を含む）。

## 決定

- research-graph は research-loop の上位互換。完全に同じでなくてよいが、元にできることを減らさない。情報を足す・穴を塞ぐのはよい。
- 元に無い重い能力（deep-research を自動で起こす等）は足さない。開いた問いは deep-research に自動で任せず、依頼者に渡すだけ（ループは待たない）。
- 案内の文言は元のまま。
- この決まりは run をまたいで効く人の方針でもある。人の方針としての正本は人が書く方針の文書（[review-graph の手順書の「人の方針」](../../graphloops/commands/review-graph.md#人の方針)）で、この ADR は決まったときの文脈と理由の記録である。食い違えば方針の文書が勝つ。

## 比べた案

- 開いた問いを deep-research に自動で任せる（捨てた案）: 元の research-loop に無い重い能力で、上位互換と言えない。
- 検索語の規律の枝の案内の文言の差し替え（6 ファイル）を取り込む: 取り込まない。

## 理由

元に無い重い能力を足すのは上位互換と言えない。

## 結果

- 止まった run の報告の直し（共有の検証器も直す）と、未解決の開いた問いを報告に並べる直しは、上位互換として 0.20.1（1449a38）に入れた。
- 開いた問いの run の R2 の作り直しの求めには、この方針（上位互換・案内を変えない）とぶつかる所が含まれる。
