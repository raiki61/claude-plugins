# 0037. 修正の記録は単位の番号で指し、行き着く先は出来事だけを書く形にする

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人（19:10）
- 実装: 一部（② は 0.21.0、① は作業枝で済み・0.21.0 には未収録、③ は未）

## 文脈

- 修正役の指示書（p3.fix）が 73〜124KB で、うち約 48KB が判定の単位の表の写しだった。配布先から「修正より記録の組み立てに時間がかかる」とフィードバックがあった。
- 同じ単位の表が 2 つの穴（単位の一覧と判定の写し）から 2 回貼られていた（BLOCKS の 6.1）。

## 決定

- 修正の入口の型を「単位の番号」にして、単位の表を写さない。
- 行き着く形は、役が短い出来事（単位 N を直した・単位 M は理由つきでやらない）だけを書き、engine が出来事と差分から今と同じ形の記録を組む形。検証器は変えない（上位互換）。
- 段: ② 返答の欄のうち差分から機械が出せる物を engine が埋める → ① 入口を番号に → ③ 出来事だけを書く。

## 理由

指示書の大半が単位の表の写しで、修正より記録の組み立てに時間を食っていた。
