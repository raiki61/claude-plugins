# 0014. 指示書に特定のリポジトリの道具名を書かず、コマンドは対象リポジトリの宣言が持つ

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人
- 実装: 0.21.0 に入った

## 文脈

- 修正差分の検算の指示書（`graphloops/prompts/review-loop/p3.delta_gates.md`）が、このリポジトリの変異テストの道具名を直接書いていた。プラグインはどのリポジトリで使われるか分からないので、特定のリポジトリに縛られていた。

## 決定

- graphloops の指示書（prompts・手順書）に特定のリポジトリの道具名を書かない。「対象リポジトリのテスト一式」のようにだけ書く。
- 具体的なコマンドは、対象リポジトリのルートの宣言 `.review-checks.json` が持つ（`suite` の各段は shell を通さない argv。任意の `mutation` の段は変異の実行器の呼び方と腕の一覧のパス。書式の正本は `graphloops/engine/declared.py`）。
- この決まりは run をまたいで効く人の方針でもある。人の方針としての正本は人が書く方針の文書（[review-graph の手順書の「人の方針」](../../graphloops/commands/review-graph.md#人の方針)）で、この ADR は決まったときの文脈と理由の記録である。食い違えば方針の文書が勝つ。

## 比べた案

- CI の定義（workflow の YAML と GitHub の式）を engine が読む（捨てた案）。

## 理由

プラグインはどのリポジトリで使われるか分からない（計画版の 2 章「起動と安全」）。

## 結果

- 配布物に道具名が戻らないよう、リポジトリのテストが配布物の文を検査している。
- 宣言の無いリポジトリの CI は任せ先の自己申告になり、収束の前に人に諮る。
- 残り: 宣言が無いときの not_run と not_applicable の区別（抽象化の run の R2）。宣言の前方互換は [0056](0056-unknown-declaration-stage.md)。
