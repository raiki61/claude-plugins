# 0029. 回す土台は乗り移る物として扱い、資産は土台に縛られない宣言として持つ

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 人（12:00 の話からの方針、16:00 の人の言葉「グラフの型にしておいて、各ブロックの保守性や組み換えがたやすい所に載っておくのが一番いい」）
- 実装: 一部（ブロックの宣言は手順 3 で進行中）

## 文脈

- Claude Code 本体に Workflow（サブエージェントを決まった手順で回す機能）が入った。回す層を各社が本体に取り込み始めている。
- 外側の部品（手順を進める・隔離・止める・型で受け付ける）は Archon・gh-aw ほか多くの土台が持ち、定番に収れんしつつある。周をまたぐ収束の判定・記録の検証器・変異テストの関門・人の方針の関所・判定と修正の分離などの中身は、どの競合にも無かった（`REPLAN-0926.md` の競合の調べ）。

## 決定

- 回す土台（自前の engine・Archon・Claude Code の Workflow・GitHub の gh-aw など）は乗り移る物として扱い、どれが勝っても載せ替えられることを第一条件にする。
- 資産として持つのは土台に縛られない宣言: ブロックの一覧と入口・出口の型（JSON Schema）・ブロックのつなぎ方の形（グラフ）・規則の関数（読み口を受けて JSON と書き込みの依頼を返す）・検証器。正本は `graphloops/blocks/`（[0030](0030-block-contracts.md)）。
- 土台ごとのつなぎ（Archon の YAML・Workflow の台本・今の graph の JSON）は薄く、捨ててよい写しにし、正本との一致を機械で確かめる。
- ブロックの中でその場で形が決まる所（観点の選び方・指摘ごとの確かめ・修正を何本並べて選ぶか）は、LLM がその場で書く台本（Workflow の型）に任せてよい。守る物は入口・出口の型と検証器に置く。長く持つ物（工程全体・周・人の関所・状態の形・記録の検査）は宣言と検査で持つ。
- 土台を選ぶ物差し: ブロックを型つきの 1 単位として置けるか・置き換え／直列／並行の組み換えが書けるか・セッションをまたいで続けられるか・人の関所があるか・走らせる前に検査できるか・版を固定できるか。

## 理由

回す層・画面は借り物で済ませて乗り換えられるようにし、投資は土台が替わっても残る物（検証の考え方と手順・事故の知識・測った数字・外から包む設計）に置く（`REPLAN-0926.md` の 12:00 の追記）。

## 結果

- 手順 3 のブロックの約束を、今の engine・Archon・外の開発の流れのどれでも埋められる形で決める（[0030](0030-block-contracts.md)）。
- 比べる実験の数字を資産として残す。
