# 0065. engine が起こす役には利用者の CLAUDE.md・設定・フックを読ませない

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 作業メモに記載なし（手順 1 の中で決めた）
- 実装: 0.20.0 に入った

## 文脈

- 手順 1 で、判定役などに CLAUDE.md を読ませるか（`--setting-sources`）を決めることになっていた。Agent ツールで起こした道具ゼロの初見の読み手が、利用者の CLAUDE.md の 1 項目を逐語で引用した。

## 決定

- 役は `--setting-sources ""` で起こし、利用者の CLAUDE.md・設定・プラグインのフックを読ませない。道具つきの役も同じ。

## 比べた案

作業メモに記載なし。

## 理由

- 作業メモに理由の記載なし。
- 手順書は理由を 3 つ挙げる: 役が見る物は graph が宣言した物だけにする／利用者の CLAUDE.md は回す側に向けた出力の作法で、JSON だけを返す契約とぶつかる／利用者とプラグインのフックが子で発火しないので、読了の記録が回す側の読みだけになる（[review-graph の手順書](../../graphloops/commands/review-graph.md)の engine の起こし方）。

## 結果

- 組織管理の CLAUDE.md だけは外せないので、完全な遮断とは名乗らない。

作業メモに記載なし。
