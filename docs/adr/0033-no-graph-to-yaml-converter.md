# 0033. graph の JSON から YAML を作る変換器は作らず、schema の写しを機械で突き合わせる

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 人（変換器は作らない）。写しと突き合わせの形は回す側の推し
- 実装: 未（Archon の側の作業はこのリポジトリの外）

## 文脈

- Archon の節の出力の型（output_format）は節の中に直接書く物で、外のファイルを指す口（$ref の解決）が無い。

## 決定

- graph の JSON から Archon の YAML を作る変換器は作らない。
- YAML の output_format にはブロックの schema の写しを置き、pack の検査が `graphloops/blocks/` の正本との一致を機械で確かめる（今の graphcheck が「graph の enum は検証器の語彙の写し」を包含で確かめているのと同じ形）。

## 比べた案

- schema だけを差し込む小さな道具を作る: 変換器の決定に近いので取らない。

## 理由

作業メモに変換器を作らない理由の記載なし。写しの形は、外のファイルを指せない制約から。

## 結果

- 写しが古くなっても機械の検査で気づける。写しを作る手間は残る。

作業メモに記載なし。
