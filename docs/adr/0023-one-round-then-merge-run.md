# 0023. 並べた run は 1 周目で止め、2 周目にあたる総点検は合流の run 1 本で行う

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人
- 実装: 0.21.0 に入った（止める口の --stop-after-round）

## 文脈

- 判定から入る run を何本も並べて、それぞれの枝を後で 1 つの版に重ねる。

## 決定

- 並べた run は 1 周目で止める（`init --stop-after-round 1`）。
- 2 周目にあたる総点検は、全部を合流させた後の合流の run 1 本（P1 から全部の目）で行う。
- 独立設計の目（R2）が能力の後退の余地を挙げた run は、2 周目まで回して閉じる。
- この決まりは run をまたいで効く人の方針でもある。人の方針としての正本は人が書く方針の文書（[review-graph の手順書の「人の方針」](../../graphloops/commands/review-graph.md#人の方針)）で、この ADR は決まったときの文脈と理由の記録である。食い違えば方針の文書が勝つ。
