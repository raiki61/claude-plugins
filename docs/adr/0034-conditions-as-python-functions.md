## 文脈

## 決定

- 条件は rules の名前付きの Python の関数にする（review 29 個・research 5 個、当時）。読む欄を `cond_reads` で宣言し、engine は宣言した欄だけが見える入れ物を渡す。JSON の式の評価器は消す。
- JSON には「何を約束するか」、Python には「どう判断するか」を置く。

## 比べた案

## 理由

JSON には約束、Python には判断を置く（計画版の 2 章「作りの方向」）。
