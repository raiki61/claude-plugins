# 0048. 問題を届ける口: 宛先は自前の設定ファイル、報告の 1 行目と手元への自動の記録は既定で入れる

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 人（09:00、推しのとおり）
- 実装: 0.21.0 に入った

## 文脈

- graphloops を使っていて起きた失敗を、利用者の手元（プラグインの持続の置き場）に 1 件 1 行で自動で残し、/graphloops:intake で人が足す・まとめる・設定した宛先へ送る口を入れた。届け先の設定の置き場と、動きが 2 つ変わること（報告の 1 行目が増える・利用者の置き場へ自動で書く）が問いになった。

## 決定

- 届け先の設定は、Claude Code の userConfig（有効化のときに値を聞かれる仕組み）でなく、置き場の設定ファイル（自前）に置く。
- 報告の 1 行目（版・run・周）と、利用者の手元への自動の記録は、既定で入れる。

## 比べた案

- userConfig に置く: 入れ方が変わる。

## 理由

userConfig だと入れ方が変わるため。

## 結果

- 自前の置き場はアンインストールで消え、`--plugin-dir` で読んだ回とインストールした回で 2 つに割れる。
- 依頼が求めた動きだが、「動きを変えない」とは緊張する。
