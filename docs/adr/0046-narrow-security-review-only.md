# 0046. 武器のうち外すのは /security-review のレンズを絞ることだけにする

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人（18:50）
- 実装: 0.21.0 に入った

## 文脈

- 武器（観点・役の節・関門・受け付けの規則・engine の手当て）の台帳の第 1 版を作った: 武器 137、過去 72 run で収束した run は 0、53 の武器は何を捕まえたかが記録に残らず数えられない。外す候補を挙げた。

## 決定

- 外すのは /security-review のレンズを、認証・外部 I/O に触れる差分に絞ることだけ。
- 2 回目の差分審査・p0.prior_decisions の毎周の撃ち直し・R2 の前提不成立の腕・並行 PR の確認は残す。
- 台帳に武器の役割の種類を足し、種類ごとに測り方を変える。

## 比べた案

- 件数の少ない武器を件数だけで外す（捨てた案）。

## 理由

捕まえた件数だけで武器を測らない。まれな事故への備え・蒸し返しを防ぐ物・製品のリポジトリでだけ効く物は、件数が少なくても値打ちがある。

## 結果

- /security-review を絞る run は 2 周目まで回し、当てるべき周に起こさなければ受け付けが拒む形になった。0.21.0（82deb2e）に入った。
