# 0058. 判定の時点に当てる記録の規則は、仮の記録に検証器を試しに当てて派生させる

- 状態: 採用
- 日付: 2026-09-26
- 決めた人: 回す側の推し（checks の 2 周目の分かれ目 1。人の「自明なものは推しで」の委任による）
- 実装: 作業枝で済み（0.21.0 には未収録）

## 文脈

- 検証器だけが持っていた規則を判定の時点にも当てるようにした。1 周目は、どの規則を当てるかを手で持つ一覧と関数ごとの表で持った。

## 決定

- 仮の記録に検証器を試しに当て、そこから判定の時点の規則を派生させる（R2 の案）。
- 同じ棚卸しで推しで決めた物: 出典の実在は次の周の p2.history（web を開ける judge）が開く形で足り、機械で URL を叩く形は入れない（分かれ目 2）。注記の追随を機械で拾う形は、テストの移し替えと F3 の doctor の側で扱う（分かれ目 3）。

## 比べた案

- 手で持つ一覧と関数ごとの表（1 周目の形）。

## 理由

- 手で持つ一覧だと、既存の関数に fail を足してもどのテストも赤にならず、抜けが黙る。
- URL を叩かない理由: 網の依存が増える。
