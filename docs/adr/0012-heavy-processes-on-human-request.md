# 0012. 重い工程は人の指示のときだけ起動し、言葉の「工程に回して」では起動できる形を残す

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 人（19:50、案 B）
- 実装: 0.20.2 に入った

## 文脈

- [0011](0011-disable-model-invocation.md) の案 iv は、入口に気づけなくなる・言葉の依頼で起動できなくなる、という代償があった。

## 決定

- 重い工程（review-graph・research-graph・/review-loop・/research-loop）は人の指示のときだけ起動する。AI は自分の判断で起動せず、提案までにする。
- 人が言葉で「工程に回して」と頼んだときは、AI が起動できる形を残す（案 B）。本体のコマンドに `disable-model-invocation` は付けない。自分の判断で起動しないことは description と案内で示す。
- この決まりは run をまたいで効く人の方針でもある。人の方針としての正本は人が書く方針の文書（[review-graph の手順書の「人の方針」](../../graphloops/commands/review-graph.md#人の方針)）で、この ADR は決まったときの文脈と理由の記録である。食い違えば方針の文書が勝つ。

## 比べた案

- 案 iv（[0011](0011-disable-model-invocation.md)）: コマンドに disable-model-invocation を付け、案内を別に置く。

## 理由

トークンをかなり使うので人が決めたときだけ回したい。一方で、description を消すと AI が入口に気づけず、言葉の依頼でも起動できなくなる。

## 結果

- 今壊れてはいない揺れ: 「工程に回して」だけだと /review-loop と review-graph の 2 本に割れ、既定のモデルで 3 回中 1 回は聞き返した（確認が 1 往復挟まるだけ）。
- 効き目が測れていない所: description の「場面に当たったら提案する」は 24 回中 0 回出た。
