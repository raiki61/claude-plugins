## 文脈

- 共有の辞書 loop_state は 68 鍵あり、綴り違いが黙って既定値に倒れる穴があった。68 鍵を「ブロックの出口の欄 19・run 全体の状態 10・消せる 39」に分けた。

## 決定

- 型の名前 `state_schema` と、鍵ごとの合わせ方（reducer）の意味は LangGraph から借りる。独自の合わせ方の語は x-reducer に改める。
- 節が全体の状態を書く口は Serverless Workflow 1.0 の export と AWS Step Functions の Assign、「依存に書いた工程の出力しか読めない」約束は GitHub Actions・Argo の needs、履歴から作る値 `hist.` はイベントソーシングの projection と Temporal の Query に倣う。旧い盤面は upcaster で読む。
- `hist.` は読み取り専用・いつでも作り直せる・履歴に何も足さない。盤面を直接読む人と AI のために、「正本でない」印を付けた控えを盤面の隣に書き出す。
