# 0063. 役は engine が claude -p の子プロセスとして起こし、子の終了を直接待つ（手順 1）

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 作業メモに記載なし（計画の手順 1 として 0.20.0 で入れた）
- 実装: 0.20.0 に入った

## 文脈

- 回す側と役の間に挟んでいた小さな AI（運び手）が、写していないのに「写した」と返した。回す側が役の完了の知らせだけを待ち、知らせが届かず 7 時間止まった。

## 決定

- 道具を持つ役も engine が `claude -p` で子プロセスとして起こす: 指示書を組む → 起こす（道具の一覧・権限・sandbox を役ごとに明示）→ 返答を受け付ける → 拒んだら同じ会話に出し直させる（`--resume`）→ 所要時間・往復数・費用を `trace.jsonl` に残す。
- engine は子の終了を直接待つ。運び手は廃止する。

## 比べた案

- Agent ツールで役を起こす: 役の返答が回す側の会話に入り、それを避けるために挟んだ運び手が書いていないのに書いたと返す・完了の知らせが迷う、を起こした（[先行例の見立ての「結論の見立て」](../graphloops-prior-art.md#結論の見立て)の 2026-09-25 の改め）。

## 理由

止まっても気づかない・中継の写し違いを、構造で消すため。

## 結果

- 期限を外せた（[0007](0007-no-deadlines.md)）。
- 定義が道具の一覧を持たない役（comment-analyzer）・ファイルを書く道具を持つ役は engine が起こさず、回す側が Agent ツールで起こす形が残る。
