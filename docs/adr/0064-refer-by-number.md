# 0064. 役は一覧を番号で指し、engine が名前に戻す（手順 2）

- 状態: 採用
- 日付: 2026-09-25
- 決めた人: 作業メモに記載なし（計画の手順 2 として入れた）
- 実装: 0.21.0 に入った

## 文脈

- 役が判定の単位などの長い key を字面で写し、写し違えた。

## 決定

- engine が一覧に番号を振り、役は番号で指す。`done` が名前に戻してから rules と記録に渡す。
- 役が自分の返答の中で自分の配列を指す欄（判定者の units を指す欄・外部標準の順位）は、字面のまま残す。

## 比べた案

作業メモに記載なし。

## 理由

- 写させない。
- 自分の配列を番号で指す形にしない理由: 自分の配列の位置の数え違いは、黙って別の値に当たって拒まれないため。

## 結果

- 当てたのは、他の節の一覧を指す欄（単位・事前審査の穴・修正の応答・答える義務・前の周の削除候補と宣言した穴）。
