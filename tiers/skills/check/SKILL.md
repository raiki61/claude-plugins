# 要る道具の段ごとの点検

段は、要る外の道具で分ける。上の段は下の段を含む。

- 段 0: Claude Code だけ
- 段 1: gh（GitHub の CLI。入っているか、ログイン済みか）
- 段 2: herdr（入っているか、動いているか）と、アカウントの起こし方の命令
- 段 3: Archon

## 走らせ方

Bash の道具で、点検したい段を渡して走らせる（`tiers` はこのプラグインの `bin/` に在り、Claude Code が PATH に入れる）。

```bash
tiers --tier <段>
```

- 段が分からなければ、呼んだプラグインの README の「要る段」を見る。それも無ければ `--tier 3` で全部を見る。
- 段 2 で、複数のアカウントを別々の命令（シェルの関数など）で起こしているなら、命令ごとに `--launcher <命令>` を足す。省けば `claude` だけを見る。
- 機械で読むなら `--json` を足す（形は `lib/tiers_check.py` の頭に在る）。
- 終了コードは 0 = そろっている、1 = 足りない物がある、2 = 使い方が違う。

## 足りない物があったとき

出力の「入れ方（手で）」の行を、そのまま持ち主に見せて止まる。入れる命令やログイン（`gh auth login`）を自分で走らせない。どれも利用者の PC に道具を入れる・アカウントを結ぶ操作で、持ち主が自分で決めて打つものだから。持ち主が済ませたと言ったら、同じ命令で点検し直す。
