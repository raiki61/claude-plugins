# メインブランチに今残っている、ルートの tests/run.sh の赤（失敗した検査）の名前の一覧（tests/land-check.py が読む）。
# 読むのは、メインブランチに入れるゲートが止まったときか、赤を直す・足すとき。ふだんは触らなくてよい。
# 1 行に 1 つ、tests/run.sh の赤の行「  FAIL <名前> — <食い違い>」の <名前> と一字一句同じに書く。
# 名前に「 — 」を含む検査は載せられない（tests/land-check.py は赤の行の最初の「 — 」までを名前として読む）。
# メインブランチに入れるゲート（.claude/company.toml の [land] の check）は、この一覧に無い赤で止まり、
# 一覧に在るのに緑になった検査でも止まる（赤を直した部署が、同じ変更でその行を消す）。CI はこの一覧を読まない。
# 行を足すのは、その赤を直す部署が決まっているときだけ（決まっていない赤は一覧に無いので、ゲートが止まる）。
# 行の上のコメントに、その部署への頼みの受付を書く。部署は、このリポジトリのプラグイン works-dispatch が
# 仕事ごとに立てる、別の会話と作業場。受付は、works-dispatch で部署に頼みを渡したときに付く ID
# （形は 20261019-004059-6a98d9）。頼みを受けた部署が、その赤を直す。
# 1 つの頼みで赤を 2 つ以上頼んだときは、同じ受付が 2 つ以上の行に付く。
