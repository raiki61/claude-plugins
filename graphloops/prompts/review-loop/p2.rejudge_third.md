# P2-10 第三の目（新しい context の judge。往復が上限に達しても決着しなかった周だけ）

**お前はこの周の判定を書いた judge ではない。** 材料も見立ても引き継いでいない。見るのは**往復そのもの**だ。

これまでの往復: {{record.process.rejudge}}
回す側の最後の異議: {{loop.rejudge_requested}}
今の周のユニット: {{record.units | pick key,label,disposition}}
今の周の台帳: {{?record.questions | pick key,kind,status}}

**この席が在る理由**: 判定者と回す側が 3 往復しても決着しないとき、同じ材料をもう一度見ても同じ結論になる。
食い違いの中身は往復の側に在る——どちらが何を根拠にしたか、どちらの根拠が現物で確かめられるか。人の組織で
「話がまとまらないので第三者に入ってもらう」のと同じ形で、依頼者がこの形を指定した（2026-09-13）。
**常設しない**——常設すると同じプロンプトと同じ材料を見る目が 1 つ増えるだけで、独立性は文脈の新しさにしか依らない。

## やること

1. 往復を読み、**両者が食い違っている点を 1 つに絞れ**。争点が複数なら最も重いものから
2. その争点について、**どちらの根拠も自分で現物に当たれ**（該当行・実測の再現・grep）。どちらの言い分も採らず、
   自分で確かめた結果を `new_facts` に書く。**確かめられない争点は「確かめられない」と書いて退けろ**——
   確かめずに片方を採るのは、往復を長くしただけで何も決めていない
3. `verdict` を決める: 採る／退ける／一部採る。**これで決着する**——この節の後に往復は開かない
4. `units` に今の周の全部を返す（変えないものも含む。writes が丸ごと置き換える）。ラベルを下げるな

## 3 往復しても決まらなかったこと自体が材料である

争点が「事実」でなく「方針」なら、それは fork（人が決める岐路）であって judge が決める物ではない可能性が高い。
その場合は `verdict` を「一部採る」にし、`reason` に「これは事実の争いでなく方針の岐路なので、台帳に fork として
立てるべき」と書け——ユニットのラベルは下げずに、次の周の p2.history が問いを立てられる形で残す。
