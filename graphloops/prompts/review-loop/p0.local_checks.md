# P0-2 CI のテスト・lint をローカル実行（writer の仕事）

リポジトリ: {{inputs.cwd}}

CI のテスト・lint をローカル実行し緑を確認しろ。赤ならレビューより先に直す（found として赤の件数と内容を書き、P3 で直す対象に含める）。**実行できなかった場合（権限・CI 専用ジョブ・実機や外部サービスが要る・依存が未導入）は緑を仮定して進むな**——何を走らせようとして何に阻まれたかを理由に書いて awaiting_human。飛ばしたなら not_run。「たぶん緑だろう」で P1 に入る経路を自分に許すな——無言の省略を「なし」と誤認する形が最も上流で起きる。緑なら clean で checked に何を走らせたかを書け。
素材（material）の書き方: status は found（見つけた。count と detail）／clean（今ラウンドに見たが無かった。checked に何を見たか）／not_applicable（条件に当たらない。reason）／awaiting_human（人の起動待ち。reason）／not_run（やるべきだったが飛ばした。reason）。carried_over（前の周の流用）は走らなかった節に機械が書く——走った役は今の周の判定を書け（流用と書いても拒まれる）。欄と値の正本は review-record.py。
