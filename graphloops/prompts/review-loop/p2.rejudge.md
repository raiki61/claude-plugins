# P2-9 同じ周の擦り合わせ（同じ judge。回す側の異議を次の周へ送らない）

回す側が**今の周に**異議を出した。中身:
{{loop.rejudge_open}}

今の周のユニット: {{record.units | pick key,label,disposition}}
今の周の台帳: {{?record.questions | pick key,kind,status}}
自分の見立て（P2 で書いたもの）: {{?record.process.diagnosis | pick framing,one_shot}}

**この工程が在る理由**: 散文の規律は「判定に異議があるなら自分で覆さず、別 context の役に再判定させろ」と書くが、
graph にはそれを同じ周に閉じる辺が 1 本も無かった。実運用では engine の外の会話で往復が起き、記録にも trace にも
残らない——記録上は「1 回で通った節」と区別できない（実測 2026-09-13: この run で往復が 5 回起き、残ったのは 1 件だけ。
うち 2 回は engine のコードが判定の最中に変わる重さだった）。この節を通せば、往復そのものが done として盤面に残る。

## 規律（依頼者の指定。4 条件のうち 3 つをここが持つ）

1. **反論は新しい事実を伴うときだけ通る**——「納得いかない」では開かない。回す側が出した事実（実測・コード上の因果）を
   **お前が自分で確かめろ**。確かめた結果を `new_facts` に書く。**確かめずに採るのも退けるのも禁じる**——どちらも
   判定を都合よく使うことになる（機械が空同然の new_facts を拒む）
2. **往復は 3 回まで**。超えても決着しなければ、新しい別の judge が会話に参加してそれまでの往復を材料に判定する
   （`p2.rejudge_third`。常設ではなく、そのときだけ立つ）
3. **判定を確定する権限は移らない**——units を書き換えるのはお前で、回す側ではない。退けてよい

## やること

1. 回す側が挙げた事実を、**現物で確かめろ**（該当行・実測の再現・grep）。確かめられないなら確かめられないと書け
2. `verdict` を決める: 採る／退ける／一部採る
3. 変える必要があるユニットだけを `units` に書く（**変えないユニットも含めて今の周の全部を返せ**——writes が
   units を丸ごと置き換える）。ラベルを下げるな（[block] → suggest は禁止）
4. `reason` に、なぜその判定かを 1 行

**自分の処方が誤っていたと分かったら、そう書け。** この周に実例が出ている——判定者が書いた零処方が 1 語足りず、
当てた回す側の側で台本が赤くなった。誤りを認めた判定は、認めなかった判定より次の周に効く。
