# 変更の記録（attention）

attention の版ごとの、利用者に効く違いを新しい順に並べる。形は [Keep a Changelog 1.1.0](https://keepachangelog.com/ja/1.1.0/) に従い、版の番号は [Semantic Versioning](https://semver.org/lang/ja/) の形（x.y.z）で振る。節は Added（足した）・Changed（変えた）・Deprecated（やめる予定）・Removed（消した）・Fixed（直した）・Security（安全の直し）のうち、中身の有るものだけを使う。

版を名指しする git の tag（例: `attention--v0.25.1`）の名前の決まり・付け方・付ける commit の一覧への案内と、この記録を書き足す段は、リポジトリのルートの `docs/releasing.md` に在る（プラグインとして入れた実体には無いので、clone か GitHub で見る: https://github.com/raiki61/claude-plugins/blob/main/docs/releasing.md）。

## [Unreleased]

## [0.25.1] - 2026-09-16

### Fixed

- Windows で /catchup を番号か URL で呼んでもブランチへ移らなかったのを直した。remote の path が `\` 区切りのとき、origin を当のリポジトリと読めていなかった。

### Security

- `--out` で書く一時ファイルを、本人だけが読める権限（0600）で作るようにした。Linux の /tmp では、同じマシンの別の利用者が PR / issue の中身を読めた。ファイル名も一意になり、同じ秒に 2 回走らせても上書きしない。

## [0.25.0] - 2026-09-16

### Added

- 3 コマンドのスクリプトに `--out` を足した。報告を一時ファイルに書いてパスだけを返すので、Claude Code の出力の上限に当たって走らせ直すことが無くなる。報告には節ごとの行番号が付き、要る節だけを読める。

### Changed

- 3 コマンドの allowed-tools に Read を足した。報告のファイルは Read で読み戻す。

### Fixed

- gh / git の呼び出しに timeout を付け、応答が無いときに止まったままにならないようにした。
- Windows で gh の出力を読むときに、文字コードの誤りで落ちるのを直した。

## [0.24.1] - 2026-09-10

### Changed

- /catchup と /what-am-i-doing の説明に付く系の絵を、部品が 2 つ以上あって関係が言えるなら描くようにした。描かないのは、部品が 1 つ・関係が無い・焦点を指摘か CI に絞ったときだけ。

## [0.24.0] - 2026-09-10

### Changed

- /catchup の指摘の枠: 相手が直したと返した件では、自分の発言以降の変更に帯を入れた関数まるごとを出す。変わっていない・関数の外のときは 1 文でそう言う。
- 指摘の行の枠は共通の字下げを落とし、落とした桁数を見出しに書く。
- 8 行を超える文字列リテラルは、先頭 3 行・点線・末尾 1 行に畳む（地図の枠にも効く。docstring と変更を含むものは畳まない）。
- 返答の太字の 1 文に取り込み先の PR と誰のものかを入れ、引用と帯なしの断りの書き方を揃えた。

### Fixed

- 字下げのあるメソッドで関数の範囲が class 全体に広がり、枠が前後 5 行に落ちていたのを直した。
- 指摘の当の行が 60 桁で切られ、確かめたい所が消えていたのを直した。

## [0.23.0] - 2026-09-06

### Added

- /catchup が commit の範囲 A..B を受ける。1 commit と同じ形（commit の一覧・木・変更の中身の枠と飛び先）で出し、`--frame` も効く。

### Changed

- /catchup の会話の話題が番号・ブランチ・commit に結び付くなら、その対象として説明と地図まで出す。このセッションの commit が複数ならその範囲で出す。
- commit・範囲の新規ファイルが 1 ファイルの上限を超えたら、案内 1 行でなく先頭と骨組みを出す。

## [0.22.0] - 2026-09-06

### Added

- /catchup が commit（sha・HEAD~n・タグ）とブランチ名を受ける。origin にだけ有るブランチも取って移る。

- 閉じた件は「済み」と出す。枠の言語名は機械が決めて見出しに置く。

### Fixed

- HEAD~n をブランチ名と取り違えていたのと、commit の本文の空行と続きの断りの崩れを直した。
