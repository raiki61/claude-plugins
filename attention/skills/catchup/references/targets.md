# /catchup の対象と移り方（機械を呼ぶ前に、対象が素直に決まらないとき・旗を付けるときに読む）

/catchup（1 件の PR などについて、前回から何が起きたかを 1 枚の HTML のページに描くコマンド）を動かす AI が、機械を呼ぶ前に、何を対象にしてどう呼ぶかを決めるために読む。

前提:

- **機械**は `catchup.py`（`bash "${CLAUDE_PLUGIN_ROOT}/scripts/run-python.sh" "${CLAUDE_PLUGIN_ROOT}/scripts/catchup.py"`）。どの呼び方でも引数の末尾に `--out` を付け、返ってきた材料（AI が読む文字の報告）のファイルを Read で読む。
- **対象**は `/catchup` の最初の引数。**焦点の語**は対象の後ろに付ける `指摘`・`地図`・`CI`。
- **移る**は、機械が手元の checkout を対象のブランチへ `git switch` で替えること（旗 `--switch`）。
- `what-am-i-doing.py` は同じプラグインの、このセッションの会話の記録を読む機械（`bash "${CLAUDE_PLUGIN_ROOT}/scripts/run-python.sh" "${CLAUDE_PLUGIN_ROOT}/scripts/what-am-i-doing.py"`。`/what-am-i-doing` の中身）。

## 対象ごとの呼ばれ方

| 対象 | 例 | 移る | GitHub | 主な材料 |
|---|---|---|---|---|
| 番号 | `1505` `#1505` | PR の head へ | 見る | PR / issue |
| URL | `https://…/pull/1505` | 同上 | 見る | PR / issue |
| ブランチ名 | `feat/123-x` | そこへ | PR が有れば | PR、無ければ手元 |
| 引数なし・`this`・焦点だけ | `/catchup 指摘` | 移らない | PR が有れば | PR、無ければ手元 |
| commit | `2971ea2` `HEAD~2` `v1.2` `2971ea2..HEAD` | 移らない | 見ない | その commit（範囲なら全部） |
| 会話の話題 | `今の修正` | 移らない | 結び付いた番号だけ | 結び付いた対象か、会話 |

## 語の読み方

- 数字だけの語は番号として読む。7 桁以上で手元の commit に解ければ commit として読む（迷うなら `HEAD~n` か 8 桁以上を使う）。
- 同じ語がブランチの名前にも当たるなら、ブランチとして読む（移る）。
- 焦点の語と同じ名前のブランチ・タグは対象にできない。焦点として読む。

## 会話の話題

会話の話題は、番号でも commit でもブランチでもない語（`新しく出たもの`・`今の修正`・`さっきの 4 件` など）。

1. 先に、会話の中で何に結び付くかを解く。結び付けば、その対象で呼ぶ。ページは、その対象を直接呼ばれたときと同じ形になる。
   - 番号 → `catchup.py <番号> --out`（`--switch` は付けない。この件の作業に戻る呼び方ではない）
   - 直前に commit した話 → `catchup.py HEAD --out`
   - このセッションで入れた commit が複数 → `what-am-i-doing.py --out` の「このセッションの間に入ったコミット」の一番古い sha に `^` を付けて、範囲で呼ぶ（`catchup.py <古い sha>^..<新しい sha> --out`）
2. 会話にしか無い話題（レビューで見つけた指摘の束・検討中の案）だけ、`what-am-i-doing.py --topic "<語句>" --out` で、その語句が出た会話の往復を取る。語句は 1 つを引用符で括る（複数の語は続けた 1 句として当たる）。0 件なら、肝の 1 語か言い換えでもう 1 回打つ。
3. 2 の話題が番号に関わるなら（例: #1505 の再レビューで見つけた指摘）、`catchup.py <番号> --out` で、PR に書いたか・相手が動いたかを確かめる。

## 引数なしと、今のブランチから対象を汲む順

引数なし・`this`・ブランチ名で呼んだときは、機械が今のブランチから対象を汲む。順に:

1. ブランチの PR。
2. 無ければ、ブランチ名の番号（`chore/1513-…` → #1513）。PR か issue かは GitHub が返した種類のとおりで、機械が 1 行で断る。issue と決めつけない。
3. それも無ければ、手元だけ。機械は GitHub に聞かず、手元のブランチと未コミットの変更、既定ブランチより先の commit の差を出す。
4. 手元に未コミットの変更も、push していない commit も、既定ブランチより先の commit も無ければ、会話から対象を推定する（下）。ブランチ名で呼ばれたときは推定しない。そのブランチが対象で、差が無ければその旨を書く。
5. 推定もできなければ、聞き返す（下）。

## 会話からの推定

- 会話に直近に出たものを 1 つ選ぶ（番号・ブランチ・commit・話題。直前に commit した話なら HEAD の commit）。
- 同じ往復に複数あれば、番号 → ブランチ → commit → 話題 の順に選ぶ。2 つ以上が同じ強さなら推定せず、聞き返す。
- 会話が要約されて前半が消えていれば、先に `what-am-i-doing.py --out` で往復を取ってから選ぶ。
- 番号は、会話に URL か owner/repo が無ければ、いま居るリポジトリの番号と見る。
- 選んだ対象で呼び直す（`--switch` は付けない。移りたい人は番号で呼び直す）。番号は `catchup.py <番号> --out`、commit は `catchup.py <sha> --out`、話題は `what-am-i-doing.py --topic "<会話でその話題を指した、読む人の語>" --out`。

## 聞き返す

問いで返してよいのはここだけ。ページは描かない。

1. 手元の事実（ブランチの名前・PR も番号も無い・未コミットの変更も push していない commit も無い）を 1〜2 文で言い切る。
2. 渡せるもの（番号・URL・ブランチ名・commit・話題の語）を 1 文で聞く。
3. 末尾に、材料の末尾の「見ていないもの」の 3 項目（GitHub の PR / issue・他のブランチと worktree の状態・このセッションで何をしたか）を写す。スクリプトの名前は `/what-am-i-doing` の呼び名に替える。

## commit と焦点の語

- commit は GitHub に聞かず、手元の git の commit として出る（題と本文・木・変更の中身。merge は第 1 親との差）。範囲 `A..B` の差は A の版と B の版の間で、本文は各 commit の題（全文は `git show <sha>`）。
- 焦点の語は急ぐときの口で、既定ではない。絞った語の材料が無ければ、機械が「無い」と 1 行出す。`指摘`・`CI` は PR と issue の物で、`地図` は commit にも効く。

## 移る

- 移る先:
  - PR は head のブランチ。手元に無ければ、origin からその 1 本だけ fetch して作る（名前と追跡先は `gh pr checkout` と同じ）。
  - issue は、名前にその番号を持つ手元のブランチが 1 本だけのとき、そこへ（origin は探さない）。
  - ブランチ名はそのブランチ。origin にだけ有れば、それを追跡するブランチを作る。
- 移らない条件: 追跡ファイルに未コミットの変更が有る（未追跡のファイルだけなら移る）・merge か rebase か cherry-pick の途中・別の worktree に checkout 済み・origin にももう無い（merge 済みで消えた）・fetch の失敗・fork の PR で手元の同名のブランチが head の commit を含まない・`index.lock` が有る。
- 移らなかった訳と今居るブランチは、材料の見出しの URL の直下の「ブランチ」の行に出る。ブランチ名で移れなかったときは、機械がそのブランチの PR を、PR が無ければブランチの先端の commit を出す。
- 機械が手元を変えるのは `git switch` とその 1 本の fetch だけ（pull・merge・stash・commit はしない）。戻すのは `git switch -`。
- 移ったときと既に居たときは、材料の末尾に「手元のブランチ」のセクション（push していない commit・PR の head より先の commit の数・未コミットの変更）が付く。

## 旗

| 旗 | 効き | 効く対象 |
|---|---|---|
| `--full` | 本文・発言・件数の上限を外す | 全部 |
| `--frame <path>` | その 1 ファイルの変更を上限なしで出す | PR・commit |
| `--limit N` | その後の出来事の件数（既定 12） | PR・issue |
| `-R owner/repo` | リポジトリを指す | 番号 |
| `--me <login>` | 「私」を替える | PR・issue |

手元の未コミットの 1 ファイルを上限なしで見るのは、`what-am-i-doing.py` の `--frame`。
