open 全件を見渡すフェーズにいる。

いま話題が 1 件（特定の PR・issue・ブランチ）に閉じているなら、ここで止めろ。スクリプトは走らせず、
その 1 件には `/catchup <番号>` を使う。全件走査はその答えを出さないし、母集団を 1 件に絞る引数も無い。

## 役割分担

- **スクリプト（機械）**: 母集団を固定し、ボールと判断材料（私のボール / 待ちの別・作者・障害の持ち主・自分のレビュー・相手の沈黙・逃がした先の生死・呼びかけとスレッドの全文）を全部出す。判断はしない
- **あなた（AI）**: 材料を読んで「返信が要るか」「見て閉じるだけか」を判定する。母集団を増減させない

## やること

1. `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/whoseturn.py --materials $ARGUMENTS` を実行する（引数なし＝自分。`<login>` で他の人、`--all` で全員分を人別に）。出力は `==== ここから下は判定の材料。貼らない ====` の印で 2 つに分かれる。上が報告、下が呼びかけ投稿とスレッドの全文。

2. 「呼びかけに返信が無い」の各行を、印の下の全文と添えられた事実（直前はあなたの発言 / 👍 済み / open PR が参照）から 4 つに分け、根拠を 1 行ずつ付ける:
   - **要返信** — 質問・確認依頼・レビュー依頼で、まだ答えていない
   - **回答済み** — 本人の質問への答えや、本人が委ねた判断の結果。返す義務は無い
   - **FYI** — 共有・決定通知・お礼。返す義務は無い
   - **別所で継続** — 話が別の PR / issue に移っている（「open PR が参照」があればそちらを読む）

3. `### PR #N スレッド` の材料（返す番があるスレッドの、相手の最後の発言の全文）を 3 つに分け、根拠を 1 行ずつ付ける:
   - **見て閉じる** — 直した報告。コミット SHA や「直しました」で終わり、問いが無い。差分を見て resolve するだけ
   - **要回答** — 問いが返っている。答えるまでそのスレッドは止まる
   - **別所へ逃がした** — 行き先の issue / PR が示されている。行に「逃がした先の open issue で、参照後に動いていないもの」があれば、そこが落ちかけている

   全文で決められないとき（前後の文脈が要るとき）だけ `gh pr view N --comments` / `gh issue view N --comments` で読む。毎回読み直すな——出力は既に本文を持っている。推測で決めるな。

4. PR は「私のボール（今日動かせる）」と「待ち（相手が動くまで進まない）」の 2 節に機械で分かれている。**節を言い直すな。** 挙げてよいのは、出力に並んでいる事実どうしの食い違いだけ——「承認済みなのに未解決スレッドが残る」「レビュー依頼が出ているのに相手が何日も無言」「逃がした先が動いていない」など。節の名前や定義の言い換えは、ずれではない。

## 守ること

- **「見ていないもの」に「該当 N 件」が付いた行は、上の判定の穴が実際に開いている場所。** 上の判定と食い違う心当たりがあるときだけ、挙がっている番号を `gh` で読んで確かめる。毎回全部読むな。読まなかったなら「見ていない」と書き、埋めたことにするな。
- **日数はスクリプトが出した数字をそのまま使う。** 「最後の発言」の日付から数え直すな。日数は今の状態になってからで、誰にも依頼していない PR は最後に動かした日から数えている。発言日から数えると放置に見える。
- **出力に無いことを断定するな。** 材料が足りなければ「材料に無い」と書く。節の名前の言い換えで埋めるな。

## 返答の形（この順で、これだけ）

1. **印より上の出力全文を 1 つのコードブロックで。** 1 文字も変えず、1 行も削らない。長くても全文。印より下（材料）は貼らない
2. 「呼びかけ」の判定表。列は `番号 / 発言者 / 判定（AI） / 根拠`——判定はコードブロックの中（機械）と違って読みで揺れるので、列名で境目を示す
3. 「スレッド」の判定表。列は `PR / 場所 / 判定（AI） / 根拠`。**要回答** が 1 件でもあれば先に挙げる
4. PR の形式と実質のずれがあれば箇条書き。無ければ「なし」

「詳細はスクリプト出力の通り」「要点だけ」のような要約で 1 を置き換えるな。出力を読む人は 1 を見て母集団と上限と見ていないものを確かめる。

## やらないこと

- `gh pr list` / `gh issue list` / `gh search` で一覧を組み立て直すな。取り方の正本は同梱の `scripts/whoseturn.py` で、判定の定義と見ていないものは `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/whoseturn.py --help` にある。
- 出力に無い項目を足すな。スクリプトが失敗したら、そのエラーをそのまま報告して終わる。
