{{prFiles}}

PR の会話を先に読み、次に共通の決まりが名指す正当化のファイル、その次に差分のファイルを読む。

{{lenses}}

1. purpose: この PR が何のためにあるかを、手段を全部抜いた 1 文で。人が欲しい結果であって、この PR がそれをどう得るかではない。差分を読む前に、PR の本文と、PR が閉じる issue から取る。
2. means: この PR が選んだ手段の 1 つずつを、PR が書いた字のまま 1 件ずつ（ツール・仕組み・ファイルの置き方・検査・名前の組み方）。字を写し、言い換えない。
3. kind: どんな種類のシステムで、触る部品がそこで何を揃えたいかを 1 文で。決まった分類は無い。このリポジトリの語も、この PR の選択を名指す語も使わない（この文は PR を見てはいけない読み手に渡る）。上の手段の語は、purpose にも kind にも入れない。
4. claims: PR が挙げる理由と、PR が言い切る「できない」「要らない」「もう扱っている」の全部を 1 件ずつ（本文・コメント・commit のメッセージ・コードのコメント・PR が足す記録の中の物）。主張を書いてあるとおりに写し、在り処（path と行か、コメントの URL）を添える。
