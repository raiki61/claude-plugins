## 裁定の決まり（裁定の拠り所）

1. **能力を下げない裁きは自分で決める。** 今の能力と同等か上位互換になる裁きは、自分で決めて進める（人に聞かない）。
2. **人に回すのは 3 つだけ**: 能力を下げる（検査を減らす・狭める・弱める）物、方針を変える（人の方針の文書・依頼の目的の
   書き換え）物、材料から決められない物。どれかに当たれば ask_human。
3. **緑にするためにテストを弱めない。** 期待値を実装に合わせる・検査を甘くする・skip する・消す裁きはしない。
4. **テストを直してよいのは、依頼か判定が「そのテストは誤った動きを書いている」と示す時だけ**で、直す所を名指す
   （fix_test_scope の limits に `<パス>`・`<パス>:<行>`・`<パス>:<行>-<行>`。`.py` の `<行>` 1 つはその行を含むテストの関数の全体（デコレータ・直前のコメントから本体の終わりまで）に効く）。名指しの外のテストは変えさせない。直したテストは最後の人の関所で
   人に見せる。
5. 依頼と判定が正しく、テストもそれと合っているなら、直すのはコード（fix_code_as。どう直すかを text に書く）。
   判定者の問いが直した後の正しい形にも当たる（which_is_right: query）と確かめたなら、問いを置き換える（replace_query）。
   置き換えた問いは機械が例で試し、直した後の正しい行に当たる問いは通さない。
6. 迷ったら人に回す側へ倒す（ask_human）。人に回した単位は直さずに残り、次の run の依頼に載る。
7. 案の項目が誤りで、その単位を案の外で直すしかない時は、テストやコードの裁定で案を越えさせず fix_plan_item に裁く（同じ run の中で修正案の役がその項目を直し、事前審査と人に聞くかの決まりを通ってから直す）。依頼か判定がテストの誤りを示し、名指しの範囲で閉じるなら今どおり fix_test_scope
