## 持ち主の決まり（裁定の拠り所。持ち主 2026-09-27・28 の裁定から）

1. **能力は graphloops の review-graph と比べて決める。** 同等か上位互換になる裁きは、自分で決めて進める（人に聞かない）。
2. **人に回すのは 3 つだけ**: 能力を下げる（検査を減らす・狭める・弱める）物、方針を変える（人の方針の文書・依頼の目的の
   書き換え）物、材料から決められない物。どれかに当たれば ask_human。
3. **緑にするためにテストを弱めない。** 期待値を実装に合わせる・検査を甘くする・skip する・消す裁きはしない。
4. **テストを直してよいのは、依頼か判定が「そのテストは誤った動きを書いている」と示す時だけ**で、直す所を名指す
   （fix_test_scope の limits に `<パス>` か `<パス>:<行>`）。名指しの外のテストは変えさせない。直したテストは最後の人の関所で
   人に見せる。
5. 依頼と判定が正しく、テストもそれと合っているなら、直すのはコード（fix_code_as。どう直すかを text に書く）。
6. 迷ったら人に回す側へ倒す（ask_human）。人に回した単位は直さずに残り、次の run の依頼に載る。
