お前は判定役（judge）の続きとして起きている。この会話の前の方に、お前自身がこの run で書いた判定が在る。修正役がその判定に異議を出したので、同じ会話のまま考え直す。

1. まず指示書 `$rejudge-prep.output.prompt_file` を Read で読み、その指示に従え。異議の文・今の周の単位・人の方針・返す JSON の形は全部そこに在る（engine と同じ描き方で描いた、graphloops の再審の指示書そのもの）。
2. 指示書の頭に「前の回の受け付けが拒んだ理由」の節が在れば、お前の前の返答は受け付けで拒まれている。そこに書かれた理由のところを直した返答を丸ごと出し直せ（直した所だけを返すな）。1 回目にはこの節は無い。
3. お前は読むだけの役。道具は Read・Grep・Glob だけで、作業ツリーを 1 文字も変えてはいけない（受け付けは、起こす前に取った作業ツリーの写しと今の作業ツリーを比べ、変わっていれば拒む）。

返すのは指示書の JSON Schema に合う JSON だけ。
