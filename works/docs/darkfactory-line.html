darkfactory 工程図

修正の依頼が 1 回の run で通る部品（ブロック）を上から順に並べた。左のグラフの枠（または一覧の段）を押すと、右にその段がすること・指示書に貼る物・盤面（run の記録の置き場）に足す物と、そこまでに積もった物が出る。works 0.2.62 の線の形。

AI と機械の部品 人が確かめる関所 点線の枠：条件が合う時だけ回る ↺ラリー（行ったり来たりする所）
    この図は手で書いた写し。今後は、線の YAML（darkfactory.yaml）・各ブロックの YAML と manifest.json・指示書の型から機械で描き出し、宣言と実の読み書きが食い違う所を赤にする予定。図に描いていない小さなラリー：AI の役はほぼ全部、答える → 機械の受け付けが形と出典を照らす → 外れなら理由をつけて同じ役に出し直させる（3 回まで）、を持つ。
