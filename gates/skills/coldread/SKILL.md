# 冷読チェック

外部へ出す文章を、書き手の文脈を持たない読み手(coldreader)に読ませ、詰まった事実を集めて直す。
書き手は全文脈を持つため「読者が持っていない前提」を自己評価では検出できない。
評価器と被験者を分離することがこの手順の目的である。

「冷読」はこのプラグインの自作語で、読み手の役は **coldreader** の名で呼ぶ。英語の
cold reading は演劇の初見読み上げ・占い師の話術を指す別の語(文書の初見検査の慣用は
fresh eyes / first-time reader)。外部向け文書では毎回説明を書くより coldreader の名で指し、
初出にだけ短い注(文脈ゼロの読み手)を添えること。

## ゲートに止められたとき(gh への投稿)

gh への投稿は、同梱のフックが coldreader を自動で走らせる。deny メッセージに coldreader の
「詰まり」がそのまま載っているので:

1. **直す前に、指摘の類型を言語化する**(例:「読者が持っていない前提に寄りかかっている」)。
   その類型で本文全体を掃討し、指摘された 1 箇所だけを直して終わりにしない。
2. 直した本文で同じコマンドを再実行する——新しい coldreader が直した本文を検査する。
3. 「疑問: 」は投稿を止めない申し送りで、反映するかは判断してよい。
   「補完: 」は coldreader が推測で埋めた箇所で、これも止めない——ただし**意図と違う補完は
   詰まりより重い**。読み手は自信を持って誤読しているので詰まりとして出てこないし、
   通ってしまえば誤読のまま読まれる。時制・主体・範囲の補完は特に確かめること。
4. 軽微と判断した詰まりを残して通すとき・3 回以上止まって指摘が揺れているときは、
   コマンド先頭に `COLDREAD_SKIP=1` を付けて通せる(スキップは記録に残る)。

## 手で検査するとき(投稿以外の文章——文書・メール等)

1. 検査対象の本文を一時ファイルに保存する。
2. coldreader を新規エージェントとして立てる(model は sonnet)。会話の文脈を渡さず、
   次の依頼文と本文だけを渡す。

   > あなたは、この件について何も知らないエンジニアです。手元にあるのは次の文章だけで、リポジトリも会話の経緯も見ていません。文章を上から読み、次の 5 点だけを報告してください。点数や総評は不要です。
   > (a) この文章があなたに求めていること(読んで何をすべきか・何を返すべきか)が言えるか。言えないなら、どこで迷ったか
   > (b) 冒頭 3 行を読んだ時点で「何の話か・自分に関係があるか・どれくらい急ぐか」が言えたか。言えなかったなら、どこで止まったか
   > (c) 文章の中だけでは意味を解決できなかった略語・識別子・参照(パス・節番号・記号)の列挙
   > (d) 意味を推測で埋めた箇所と、埋めた推測の中身
   > (e) 読み終えて残った疑問

   用事(a)を先に置くのは、タスクの無い通読が感想収集に退化するためである。
3. 指摘の類型を言語化してから同型を掃討する(上と同じ)。
4. coldreader を**新しく**立てて再検査する。前の coldreader は直した本文の文脈を既に持っているため
   使い回さない。新しい指摘が出なくなったら収束(最大 3 巡)。

## 書き方の規則(直すときの基準)

- **ポインタは初出で「中身→ポインタ」の順に置く。** パス・節番号・識別子・略語は、
  読者が参照解決できて初めて意味を持つ。「署名アルゴリズムの名前(`alg`)」のように書く
- **冒頭 3 行で「何の話か・自分に関係があるか・急ぐか」に答える。** 権威づけは答えにならない
- **危険の話は「今壊れているのか・壊れる余地だけか」を冒頭で言う。** 安全である事実を
  後ろに置くと、そこまで読者を緊張させたまま読ませることになり、理解が落ちる
- **読者の寿命で前提の厚さを変える。** issue は 3 ヶ月後に文脈ゼロで読まれるので前提を厚く。
  PR の返信はレビュアーの語彙のままでよい
- coldreader に点数は付けさせない。集めるのは詰まった事実だけ(点数は coldreader ごとに揺れて
  収束判定に使えない)。ただし**指摘の件数は数えてよい**——「新しい詰まりが 0 件」が
  収束の計器で、評点と件数は別物である

## 使い分け

リポジトリの文書(入口からの導線を含む検査)は firstread-loop を使う。本 skill と同梱の
ゲートは、issue・PR コメント等、単体で読まれる短い文章向けの軽い姉妹版である。
