# 変更の記録（gates）

gates の版ごとの、利用者に効く違いを新しい順に並べる。形は [Keep a Changelog 1.1.0](https://keepachangelog.com/ja/1.1.0/) に従い、版の番号は [Semantic Versioning](https://semver.org/lang/ja/) の形（x.y.z）で振る。節は Added（足した）・Changed（変えた）・Deprecated（やめる予定）・Removed（消した）・Fixed（直した）・Security（安全の直し）のうち、中身の有るものだけを使う。

版を名指しする git の tag（例: `gates--v0.11.3`）の名前の決まり・付け方・付ける commit の一覧への案内と、この記録を書き足す段は、リポジトリのルートの `docs/releasing.md` に在る（プラグインとして入れた実体には無いので、clone か GitHub で見る: https://github.com/raiki61/claude-plugins/blob/main/docs/releasing.md）。gates の 0.1.0 の前は、coldread という名前の plugin（coldread 0.1.0）だった。その版には gates の tag は付かない。

## [Unreleased]

## [0.11.5] - 2026-09-29

### Changed

- 認証の段（`claude_auth.py`）の冒頭の写し先の一覧に、works の写し（`works/.shared/core/`）を足した。説明の 1 行だけで、動きは変わらない。

## [0.11.4] - 2026-09-27

### Added

- 変更の記録（この CHANGELOG.md）を同梱し、README の冒頭から、変更の記録と版の出し方（リポジトリのルートの docs/releasing.md）へ案内する。動きは変わらない。

## [0.11.3] - 2026-09-16

### Fixed

- coldreader（文脈を持たない初見の読み手）へ本文をコマンドラインの引数でなく標準入力で渡すようにした。Windows で長いスレッドへの返信が、読み手の起動の失敗として全部止まっていた。

## [0.11.2] - 2026-09-16

### Fixed

- Windows の checkout で remote の URL が `\` 区切りのとき、destgate が宛先を読めず、正しい投稿を「宛先不明」で止めていた。

## [0.11.1] - 2026-09-16

### Fixed

- Windows で coldreader へ渡す本文の改行が `\r\n` に化けていた。本文を書かれたとおりに渡す。

## [0.11.0] - 2026-09-15

### Changed

- coldreader を起こすときの認証の順を「親の環境の認証 → mac は Keychain」にそろえ、どの場合も設定の置き場を子へ明示して渡す。

### Fixed

- 認証が切れていると coldreader が終了コード 0 のままエラーの 1 行を返し、「詰まりゼロ」として投稿が通っていた。判定の形になっていない出力は「検査できない」として止める。

## [0.10.1] - 2026-09-07

### Changed

- 「詰まり」の線を「その箇所で意味が取れず、次の文へ読み進められない」に絞った。根拠・出所・答えが欲しいだけのものは疑問として通し、迷ったら疑問とする。

## [0.10.0] - 2026-09-07

### Added

- 返信で読み手に渡す画面を広げた: 状態・本文・変更ファイル・本文が参照する番号の題・コメント 30 件まで。入り切らないときは古い順に落とし、答える相手の直前は切らない。
- 相手の言い回しを地の文に写した箇所を「なぞり」として止める。引用して指す形は通る。
- 記録の各行にセッション・フックの版・投稿先を残し、新しい版が入っていれば検査結果でそれを知らせる。

### Changed

- 3 回連続で止まったときの案内は字数の推移を示し、「最初の本文に戻す」を勧める。

### Fixed

- 連続で止まった回数を書き手のセッションと投稿先の組で数える。並行するセッションの deny が足され、よそでの skip で案内が消えていた。

## [0.9.0] - 2026-09-06

### Added

- PR・issue への返信と編集では、フックが gh でスレッド（題・対象のファイルと行・元の指摘・これまでの返信）を取り、coldreader に「既に見えているもの」として渡す。新規の作成は従来どおり文脈ゼロで読ませる。

### Changed

- 画面に有るものを本文で説明した箇所は「冗長」として止めずに申し送る。返信が止まったときの直し方は「足すより削る」にした。
- 3 回連続で止まったときの案内を先頭に置き、本文の字数の膨れ方を示す。
- coldreader は利用者の CLAUDE.md などの設定を読まずに起動する。
- スレッドが取れないときは文脈ゼロで検査し、画面に有るものへの詰まりは無視してよいと書き手に伝える。

### Fixed

- 読み手が「詰まり: なし」と書いたとき、詰まり 1 件と数えて止めていた。

## [0.8.0] - 2026-09-04

### Added

- coldreader の報告に「補完」（読み手が推測で埋めた中身）の欄を足した。投稿は止めず、書き手へ返す。
- 網から落ちた疑いのあるコマンドを misses.log に残す。残すのは旗の綴りだけで、値は残さない。

### Changed

- 止めたときの指摘を「直す詰まり」と「直さなくてよい補完・疑問」の見出しに分けた。

### Fixed

- 行継続（`\` と改行）で割れた gh の呼び出し、予約語（`{`・`!`・`then`・`do` など）の後ろの gh、注釈と行継続の組み合わせで、投稿が無検査・無記録で通っていた。destgate の宛先検査も同時に外れていた。

## [0.7.0] - 2026-08-28

### Added

- destgate: 投稿先を人が管理する許可一覧（`$CLAUDE_CONFIG_DIR/destgate/allowlist` に owner/repo・owner/*・gist）で縛る門番。一覧が無ければ働かない。宛先が特定できない投稿は `-R` の明示を求めて止める。
- destgate は COLDREAD_SKIP=1 では外れない。逃げ道は一覧への人の追記だけ。

### Changed

- coldread が通したときにも「見たのは通じやすさだけで、出してよい投稿か・名義・宛先は検査していない」と毎回伝える。止めたときの文言の末尾にも同じ注を足した。

## [0.6.0] - 2026-08-28

### Changed

- 読み手の役を coldreader と呼ぶ（README・skill・止めたときの文言）。
- graphql の mutation は本文を取り出さず、一律で「検査できない」として止める。body 以外のフィールドの値まで coldreader へ送っていた。

### Fixed

- `--input -` のヒアドキュメントの本文を取り損ねると、投稿が無検査で通っていた。取り損ねは「本文の値を判定できない」で止める。
- COLDREAD_SKIP=1 を部分文字列で探していたため、門番を話題にする本文で検査が黙って外れていた。コマンドの先頭の指定だけを見る。
- 改行が CRLF のコマンドでヒアドキュメントを認識できず、正しい投稿が誤った理由で止まっていた。
- `gh project edit` の旗を実在する `--readme` に直した。

## [0.5.1] - 2026-08-28

### Fixed

- 同じ行の別コマンドのヒアドキュメント（例: `cat > cfg.json <<SEC`）の中身が gh の本文として coldreader へ送られていた。本文はそのコマンドに付いたヒアドキュメントからだけ取る。
- 単一引用で囲んだ本文（コードフェンスで始まる本文・`--body` の引用・末尾が `$` の文）が「置換渡し」として読まれずに止まっていた。実際に展開される置換が有るときだけ止める。

## [0.5.0] - 2026-08-28

### Changed

- gh の呼び出しと分かったのにサブコマンドを特定できないときは、投稿でないと見なさず「検査できない」として止める。
- `gh api --input` の JSON が `.body` 以外に長い文字列を持つときは、coldreader へ送らずに止める。

### Fixed

- 融合形の global 旗（`--repo=o/r`・`-Ro/r`・`--method=POST` など）を使うと、短縮形の本文旗が無検査で通っていた。
- 引用していないコマンド置換の本文が、断片に割れて検査をすり抜けていた。
- 長さの上限を超えたときの案内が、効かない手順（コマンドの前に環境変数を付ける）を示していた。実際の設定先を案内する。

### Security

- graphql の mutation で、引用文字列を無差別に本文として取り出し、トークンや ID を coldreader へ送っていた。

## [0.4.0] - 2026-08-28

### Changed

- 長い旗（`--body`・`--notes`・`--comment` など）は綴りだけで本文と見なし、短縮形（`-b`・`-c`・`-n` など）はその綴りが本文を意味するサブコマンドの中でだけ本文と見る。`gh pr checkout -b` などが的外れに止まっていた。
- 入れ子の遮断で検査せずに通した投稿も記録に残す。

### Security

- `gh api --input` の JSON は `.body` を持つときだけその中身を coldreader へ送る。持たない JSON（secrets の暗号値・設定）は送らない。

## [0.3.2] - 2026-08-28

### Changed

- coldreader を道具なし（`--tools ""`）で起こす。本文に紛れた指示で読み手が道具を使う経路を断つ。

### Fixed

- coldreader の中で門番がもう一度発火し、入れ子の末にフックのタイムアウトで投稿が無検査のまま通っていた。
- 長さの上限を超えたときに「引用を直せ」と誤った案内をしていた。上限の上げ方を案内し、README の設定一覧に載せた。

## [0.3.1] - 2026-08-28

### Changed

- 必要な Python を 3.8 以降と文書に明記した。

### Fixed

- 本文旗の直後のリダイレクト（`--body >&2 'text'`）、解析中の例外、検査できない本文と読める本文の同居で、投稿が無検査で通っていた。どれも止める側に倒す。
- ヒアドキュメントの `<<"EOF"`・`<<-`・ハイフン入りの終端を認識できず、正しい投稿を「stdin 渡しなので検査できない」と誤った理由で止めていた。
- `--input -` の JSON は、外側の殻でなく `.body` を coldreader へ渡す。
- `gh secret set -b`・`gh variable set -b`・`gh workflow run -F` を投稿と誤認し、値を読み手へ送ったり止めたりしていた。

## [0.3.0] - 2026-08-28

### Changed

- 投稿の判定を、シェルの単純コマンドごとに旗の持ち主を見る形に作り直した。引用の中の gh や、別のコマンドの旗を巻き込まない。
- graphql は mutation のときだけ投稿と見なす。
- 変数・コマンド置換・実ファイル・パイプで渡す本文は検査できないので止める。
- 原理的に対象外のもの（`--fill`・エディタ・ラッパー越し）を README の「網の射程」に書いた。

### Fixed

- 短縮形の `-F`・`-n`・`-c`、`--input` の実ファイル、引用の前置で投稿を取りこぼしていた。複合コマンドで別のコマンドの旗を拾って誤って止めていた。

## [0.2.2] - 2026-08-28

### Fixed

- coldreader の出力が UTF-8 でないとき、止めるべき投稿が無言で通っていた。
- Windows の python.org 版で `python3` が無くてもフックが起動する（`python3` が無ければ `python` を使う）。

## [0.2.1] - 2026-08-28

### Changed

- 利用者に見える違いは無い（内部の整備）。

## [0.2.0] - 2026-08-28

### Changed

- 検査の対象を issue・PR のサブコマンドの列挙から、本文を運ぶ旗（`--body`・`--notes`・`--comment`・`--body-file`・`--input`・`-f body=`）で捕まえる形にした。`release create` のリリースノートや `issue close --comment` も対象に入る。
- 実ファイルを指す `--body-file` は本文を読めないので止める。

## [0.1.1] - 2026-08-28

### Fixed

- Windows で日本語の deny の文言を出すときに文字コードのエラーで落ちていた。

## [0.1.0] - 2026-08-28

### Added

- gh の issue・PR への投稿を PreToolUse フックで捕まえ、別プロセスの claude（文脈を持たない読み手）に本文を初見で読ませる門番。詰まりが有れば指摘を付けて止め、疑問だけなら通して申し送る。
- 検査を飛ばす逃げ道 COLDREAD_SKIP=1（使うと記録が残る）。3 回連続で止まると、採否の判断と skip を案内する。読み手が故障したときは止める側に倒す。

### Changed

- plugin の名前を coldread から gates に変えた（skill の /coldread は gates の中に残る）。
