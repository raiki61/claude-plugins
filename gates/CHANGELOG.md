# 変更の記録（gates）

gates の版ごとの、利用者に効く違いを新しい順に並べる。形は [Keep a Changelog 1.1.0](https://keepachangelog.com/ja/1.1.0/) に従い、版の番号は [Semantic Versioning](https://semver.org/lang/ja/) の形（x.y.z）で振る。節は Added（足した）・Changed（変えた）・Deprecated（やめる予定）・Removed（消した）・Fixed（直した）・Security（安全の直し）のうち、中身の有るものだけを使う。

版の出し方（この記録を書き足す段。git の tag は作らない）は、リポジトリのルートの `docs/releasing.md` に在る（プラグインとして入れた実体には無いので、clone か GitHub で見る: https://github.com/raiki61/claude-plugins/blob/main/docs/releasing.md）。gates の 0.1.0 の前は、coldread という名前の plugin（coldread 0.1.0）だった。

## [Unreleased]

### Changed

- 手元の文書の初見読みが、前から在る文書では、書き換えた所を含む節（見出しから次の見出しの手前まで。見出しの無い文書は書き換えた行の前後の段落）と、何の文書かが分かる冒頭（題と最初の段落）だけを読み手に渡し、指摘もそこだけに求める。省いた節で説明されているかもしれない語は、詰まりでなく疑問に回させる。新しく作った文書と、抜き出しが全体の 8 割以上になる文書は今までどおり全体を読む。前の版は、その回で最初に記録したときの書く前の中身（Write・Edit はフックの入力の `originalFile`、Bash は走る前の HEAD、MCP の道具は記録したときの HEAD）。前は 1 文直すたびに、直していない節の前からの疑問が 6〜14 件返っていた。
- 書く前と同じ中身の文書は読まない。
- Bash で書いた文書として拾うのを、中身がコマンドの字面に在る書き込み（ヒアドキュメント・ヒア文字列を受けた `cat`・`tee`、`echo`・`printf`、それらをパイプで受けた `tee`・`cat`、`sed -i`）に絞る。ほかの命令の出力をリダイレクトした先（`sed -n … ci.log > x.txt` など）と `cp`・`mv`・`install` の行き先は拾わず、git の変更一覧の差からも外す。CI のログの抜粋を書いた一時ファイルを読み手が文書として読み、詰まりを返していた。

### Added

- `.gitattributes` で `linguist-generated` の印（GitHub Linguist の、生成物の印）を付けた文書は、手元の文書の初見読みで読まない。スクリプトがウェブから取った原文の写しを読み、時間切れと指摘を出していた。

### Fixed

- Bash の同じコマンドの中で文書を書いて commit すると、git の変更一覧から消えて拾えなかった。走る前と後の HEAD の差でも拾う。

## [0.14.0] - 2026-10-16

### Changed

- 投稿の関所が、本文がファイルにある形（`-F body=@file`・`--body-file file`・`--input file`）を止めずに、自分でファイルを読んで初見の読み手に渡す。読めない形（パイプからの標準入力、決まらない相対パスや変数のパス、FIFO・巨大・UTF-8 でないファイル、読んだ中身と gh が出す中身がずれうる形）だけを止める。前は全部止めてヒアドキュメントに書き直させていた（往復 124 回）。Windows では、Git Bash の形で書いたパス（`/c/…`・`/tmp/…`）を cygpath で Windows の形に直して読む。
- 逃げ道 `COLDREAD_SKIP=1` をやめた。書かれていても効かせず、効かなかったことを `skip.log` に残す。エージェントが止められた後に自分で付けて、未検査のまま出していた（22 回）。持ち主が自分で出すときは、Claude Code の `!` か自分の端末で打つ。
- 同じ投稿が 3 回止まったら、それ以上書き直させずに「持ち主に渡して止まれ」と返し、`stuck.log` に残す（本文は写さない）。
- 手元の文書の初見読みが、Bash で書いた文書（Bash の前後の git の変更一覧の差。git の外ではコマンドの書き込み先）と、MCP の書く道具の文書も拾う。Bash 1 回ごとに git の差分取りの分（手元の測りで 0.1〜0.2 秒）が足される。
- graphql の mutation を一律に止めるのをやめ、`body:` の欄だけを読む。

### Fixed

- 400 字未満のコマンドを、中を見ずに記録も残さず通していた。本文の旗が有れば短くても読む。
- review の JSON で、`.body` が有ると行ごとのコメント（`comments[].body`）を読んでいなかった。
- ヒアドキュメントの開始行で区切りの後ろに旗やパイプが続く形（`<<'J' -q .html_url`）を見落とし、誤って止めていた。
- `timeout 180 gh …` のように前に `timeout` を付けた gh を見失っていた。
- 取りこぼしの記録（`misses.log`）が、ヒアドキュメントの中の綴りや別の道具の旗を拾っていた。旗と先頭の語で残し、判定より前に書く。
- 試験の 1 本が、本物の設定フォルダの記録（`denies.log`）に書いていた。

## [0.13.0] - 2026-10-15

### Changed

- 手元の文書の初見検査を、書いた役の終わりに回す。サブエージェント（作業役）の中で書いた文書は、その作業役が終わるとき（SubagentStop のフック）に読み、指摘の全文をその作業役に返して直させる。記録はフックの入力の `agent_id` で分け、会話の終わり（Stop のフック）は作業役の分を読まない。前は作業役の書いた文書も会話の終わりに読まれ、指摘が会話の側に届いて作業役に送り直すしかなく、書きかけも読んでいた。
- 会話の側で書いた文書の指摘は、全文を `$CLAUDE_CONFIG_DIR/coldread-gate/docs/findings/` に書き出し、会話には本数・件数・ファイルの場所の短い知らせだけを返す。直すのは、そのファイルを渡した新しい作業役に任せる（推測で埋めた箇所のうち書き手の意図と違うものだけは会話の側で見る）。
- 手元の文書の読み手の effort の既定を xhigh にした（`COLDREAD_DOC_EFFORT` で替えられる）。Haiku 5.5 の xhigh が Sonnet 5.5 の medium と同じ総合点を約 4 分の 1 の費用で出した測定（convergence-loops 0.42.0 の選び直し）に合わせた。投稿の読み手は sonnet・medium のまま。

## [0.12.0] - 2026-10-15

### Added

- 手元の文書の初見検査（coldwrite から移した）。拡張子が md・mdx・adoc・asciidoc・rst・txt の文書を Write・Edit・MultiEdit で書くと、PostToolUse のフックがパスを記録し、ターンの終わり（Stop のフック）に、そのターンで書いた文書を 1 本 1 回だけ coldreader に読ませる。詰まりか推測で埋めた箇所が在れば、止めずに指摘を返して会話を続けさせる。読み手のモデルは既定で haiku（`COLDREAD_DOC_MODEL`）、投稿の読み手は sonnet のまま。300 字未満・1 行目に `coldread:skip` か `coldwrite:skip` の印・前に読んだのと同じ中身は読まない。手元の文書の門番だけを切るのは `COLDREAD_DOCS_OFF=1`。
- `coldread-gate.py read <パス>`（手で 1 本を読ませる。詰まりが在れば終了コード 1）と `coldread-gate.py prompt`（依頼文を出す）。

### Changed

- skill『coldread』の手で検査する手順は、依頼文を写して持たず、`coldread-gate.py read` を呼ぶ。初見で読む観点の正本は `coldread-gate.py` の 1 か所になった。

### Fixed

- `gh api` の直後、API のパスより前に旗（`--jq`・`-X GET` など）を置いた呼び出しを、投稿かどうか判らないとして止めていたのを直した（`gh api` の旗の一覧は gh 2.102.0 の `gh api --help` から）。

## [0.5.0] - 2026-08-28

### Changed

### Fixed

- 長さの上限を超えたときの案内が、効かない手順（コマンドの前に環境変数を付ける）を示していた。実際の設定先を案内する。

### Security

- graphql の mutation で、引用文字列を無差別に本文として取り出し、トークンや ID を coldreader へ送っていた。

## [0.4.0] - 2026-08-28

## [0.1.0] - 2026-08-28

### Added
