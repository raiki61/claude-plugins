# 変更の記録（gates）

gates の版ごとの、利用者に効く違いを新しい順に並べる。形は [Keep a Changelog 1.1.0](https://keepachangelog.com/ja/1.1.0/) に従い、版の番号は [Semantic Versioning](https://semver.org/lang/ja/) の形（x.y.z）で振る。セクションは Added（足した）・Changed（変えた）・Deprecated（やめる予定）・Removed（消した）・Fixed（直した）・Security（安全の直し）のうち、中身の有るものだけを使う。

版の出し方（この記録を書き足す段。git の tag は作らない）は、リポジトリのルートの `docs/releasing.md` に在る（プラグインとして入れた実体には無いので、clone か GitHub で見る: https://github.com/raiki61/claude-plugins/blob/main/docs/releasing.md）。gates の 0.1.0 の前は、coldread という名前の plugin（coldread 0.1.0）だった。

## [0.14.0] - 2026-10-16

## [0.13.0] - 2026-10-15

### Changed

- 手元の文書の初見検査を、書いた役の終わりに回す。サブエージェントの中で書いた文書は、そのサブエージェントが終わるとき（SubagentStop のフック）に読み、指摘の全文をそのサブエージェントに返して直させる。記録はフックの入力の `agent_id` で分け、会話の終わり（Stop のフック）はサブエージェントの分を読まない。前はサブエージェントの書いた文書も会話の終わりに読まれ、指摘が会話の側に届いてサブエージェントに送り直すしかなく、書きかけも読んでいた。
